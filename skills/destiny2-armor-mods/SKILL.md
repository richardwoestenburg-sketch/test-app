# Destiny 2 – beste armor mods per karakter

Doel: voor elk karakter een complete, direct in-game in te stellen mod-lijst geven, per slot, met een korte uitleg waarom. Richard speelt op console (Xbox/PS5, via Cross Save), dus houd het praktisch: namen zoals ze in-game heten, geen jargon zonder uitleg.

## 1. Verzamel eerst de input

Vraag alleen wat ontbreekt (maximaal één korte vraagronde). Als Richard "maak voor al mijn karakters" zegt zonder details, maak dan voor elke class een sterke **algemene PvE-build** met de meest gangbare subclass en zeg welke aannames je deed.

| Nodig | Waarom |
|---|---|
| Class (Hunter / Titan / Warlock) | Bepaalt class ability en welke exotics mogelijk zijn |
| Subclass + element (Solar, Arc, Void, Stasis, Strand, Prismatic) | Siphon-, Surge- en elementaire mods moeten matchen |
| Exotic armor (als bekend) | Bepaalt vaak welke stat en welke ability centraal staat |
| Wapens (vooral energie- en heavy-wapen) | Targeting, Loader, Scavenger, Surge en Siphon mods volgen de wapentypes/elementen |
| Activiteit | Raid/dungeon (team + boss-DPS), Grandmaster/solo (overleven), PvP (andere prioriteiten) |
| Armor-energie per stuk (standaard 10 bij masterworked) | Budget voor mods |

## 2. Controleer de actuele meta

Destiny 2 verandert elk seizoen (mod-kosten, nieuwe mods, stat-systeem). Doe vóór het advies een snelle websearch naar de huidige meta voor de gekozen class/subclass (bijv. "Destiny 2 best Prismatic Hunter build" + huidig jaar/seizoen). Bruikbare bronnen: light.gg (mod-database), mobalytics, blueberries.gg, Game Rant, YouTube-samenvattingen van Aztecross/Fallout Plays/Datto. Lukt zoeken niet, gebruik dan `references/mods.md` als basis en meld dat het advies mogelijk niet het nieuwste seizoen weerspiegelt.

## 3. Stel de build samen

Werk in deze volgorde, omdat elke stap de volgende beperkt:

1. **Stats (Armor 3.0):** Weapons, Health, Class, Grenade, Super, Melee. Kies 2–3 kernstats die de build aandrijven (bijv. Grenade voor een grenade-build) en zorg in PvE voor voldoende Health. Waarden boven 100 geven extra bonussen; stuur daar alleen op als de build er echt van profiteert. Gebruik stat-mods (+10 major / +5 minor) alleen om gaten te vullen — ze kosten energie die anders naar effect-mods gaat.
2. **Kernloop:** hoe genereert de build Orbs of Power, en wat doet hij ermee? Dit is het hart: bijv. Siphon (helm) → orbs → Recuperation/Innervation (benen) → ability-energie.
3. **Per slot** de mods kiezen (zie `references/mods.md` voor opties per slot).
4. **Energie-check:** tel per stuk de kosten op; totaal mag niet boven de energie uitkomen. Noem de kosten erbij.
5. **Activiteit-aanpassing:** Grandmaster/solo → meer resist en overleven (Concussive Dampener, element-resist, Recuperation). Raid → teamspel (Heavy Ammo Finder, Reaper/Powerful Attraction, surge-mods voor DPS-fase). PvP → minder ammo-mods, meer Dexterity/Loaders en Health/Weapons.

## 4. Output-format

Gebruik per karakter precies deze opbouw, in het Nederlands (mod-namen in het Engels, zoals in-game):

```
## [Class] – [Subclass] ([Exotic]) – [Activiteit]

**Idee in één zin:** ...

**Stats:** prioriteit [stat] > [stat] > [stat]  (+ welke stat-mods)

| Slot | Mods (kosten) | Waarom |
|---|---|---|
| Helm | ... | ... |
| Armen | ... | ... |
| Borst | ... | ... |
| Benen | ... | ... |
| Class item | ... | ... |

**Artifact-perks die dit versterken:** (alleen als het huidige seizoen relevant is)
**Alternatief:** één wissel voor als Richard een mod niet heeft of het niet bevalt.
```

Houd de uitleg per mod kort (max. één zin). Sluit af met een bronnenlijst als je webresultaten hebt gebruikt.

## 5. Richtlijnen

- Liever één samenhangende build dan een lijst "losse beste mods": mods die elkaar voeden (orbs maken → orbs gebruiken) zijn veel sterker dan individueel sterke mods.
- Siphon- en Surge-mods moeten bij het element van de gebruikte wapens passen; zeg het expliciet als dat niet klopt.
- Heeft Richard een mod niet ontgrendeld? Mods koop je bij Ada-1 (in de Tower); noem een beschikbaar alternatief.
- Wil hij de build opslaan: wijs op de in-game Loadouts (Character → Loadouts) zodat hij snel kan wisselen.
